# v2.5.0 — AI Manager

## 목표

사용자가 CRM을 관리하는 것이 아니라 AI가 매일 업무·재무·데이터 품질을 감시하고 예외만 보고한다.

## 일일 탐지

1. 다음 행동 없는 진행 프로젝트
2. 기한이 지난 고객 약속
3. 장기간 정체 프로젝트
4. 목표 이하 예상 이익률
5. 연체 미수금
6. 7일 이내 지급
7. 음수 7일 현금흐름
8. 미승인 범위 변경
9. 90일 이내 갱신
10. 오래된 확인 질문

## 출력

- Owner Headline
- Critical·Warning·Info Finding
- 오늘 기한 약속
- 7일 예상 입금·출금·순현금
- 확인 대기 수
- Finding별 권고 행동과 Evidence

## 권한 경계

AI Manager는 경고와 실행 초안만 생성한다. 고객 발송, 금액 변경, 계약·범위·지급은 직접 실행하지 않는다.

## 인수조건

위험 프로젝트, 연체 미수, 미승인 변경과 갱신 임박 데이터를 넣었을 때 각각 별도 Finding이 생성되고 Today 화면에서 우선순위 순으로 표시된다.
