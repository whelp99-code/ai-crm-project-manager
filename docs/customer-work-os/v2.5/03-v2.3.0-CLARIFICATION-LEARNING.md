# v2.3.0 — Clarification & Personal Learning

## 목표

확실한 내용을 다시 묻지 않고, 불확실한 항목만 최대 세 개의 선택형 질문으로 해결한다.

## 질문 규칙

- 원문 Evidence를 표시한다.
- 가능한 경우 선택지를 제공한다.
- 한 이벤트에 최대 3개만 노출한다.
- 나머지는 미확인 목록으로 보존한다.
- DEFER를 허용한다.

## 학습 허용

- 고객명 별칭
- 프로젝트명 별칭
- 벤더 별칭
- 비용 분류
- 문서 유형
- 고객별 커뮤니케이션 스타일

## 학습 금지

- 가격·할인 정책
- 계약조건
- 승인정책
- 보안정책
- 삭제정책
- 외부 발송 권한

## 인수조건

사용자가 “선진=선진엔지니어링”을 확정하면 다음 입력에 재사용하되, 할인율이나 승인권한은 자동 학습할 수 없다.
