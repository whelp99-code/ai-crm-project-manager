# v2.1.0 — Baseline Builder

## 목표

기존 자료를 사용자가 다시 입력하지 않고 고객·프로젝트·재무·문서의 1차 원장을 만든다.

## 입력

- Notion DB Snapshot
- Gmail·Outlook 검색 Export
- Calendar Export
- Drive 파일 목록·해시
- 회계·통장 CSV
- 수동 보정 자료

## 처리

1. 원본 ID·경로·해시 보존
2. 고객명·이메일·사업자번호 정규화
3. Project Key·프로젝트명 정규화
4. 동일 문서·거래 중복 제거
5. 여러 자료의 필드 병합
6. 날짜·금액·고객 연결 충돌 생성
7. 충돌마다 Evidence 선택지 생성
8. 모든 Blocking Question이 해소된 뒤 적용

## 자동 적용 금지

- 상충하는 계약금액
- 상충하는 실제 입출금
- 서로 다른 Project Key
- 고객이 다른 재무자료
- Evidence가 없는 확정값

## 인수조건

- 같은 Project Key는 하나의 Canonical Record가 된다.
- 동일 Source Hash는 중복 Import되지 않는다.
- 충돌값은 조용히 덮어쓰지 않는다.
- 사용자는 전체 데이터를 다시 입력하지 않고 충돌만 확인한다.
