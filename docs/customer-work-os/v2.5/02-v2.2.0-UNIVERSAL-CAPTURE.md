# v2.2.0 — Universal Capture

## 목표

사용자가 메모·메일·회의 내용을 한 번 입력하면 여러 업무 데이터를 동시에 준비한다.

## 입력 종류

TEXT, EMAIL, MESSAGE, MEETING, VOICE_NOTE, DOCUMENT, IMAGE, CALENDAR, TRANSACTION, NOTION.

## 출력 Update Plan

- Activity
- Account Link
- Engagement Link
- Project Schedule
- Requirement·Unknown
- Commitment
- Change Request
- Financial Item
- Settlement Candidate
- Document

## 신뢰도·위험 정책

- 저위험이고 신뢰도 95% 이상인 활동·연결만 Auto-ready
- 일정·약속은 Review
- 금액·계약·범위·실제 입출금은 항상 Human Approval
- Prompt Injection·불안전 첨부는 Quarantine
- 이벤트당 질문 최대 3개

## 인수조건

한 문장에 프로젝트 일정, 지급, 입금, 다음 행동, 추가 범위가 있으면 각각의 Mutation으로 분리되고, 고위험 Mutation은 자동 승인되지 않는다.
