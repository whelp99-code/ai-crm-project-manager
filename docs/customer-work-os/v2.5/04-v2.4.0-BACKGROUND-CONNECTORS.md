# v2.4.0 — Background Connectors

## 목표

외부 자료를 사용자가 복사하지 않아도 Read-only로 지속 수집한다.

## 대상

Gmail, Outlook, Calendar, Notion, Drive, OneDrive, CSV.

## 공통 계약

- Secret은 `secret://` 참조만 저장
- Cursor·Checkpoint Sequence
- Provider Event ID·Content Hash 중복 방지
- 최대 Batch Size
- 제한된 Retry
- Suspicious Content Quarantine
- Read-only → Shadow → Reconciled
- 외부 Write 없음

## 인수조건

같은 메일이 두 번 수신돼도 원본 1건과 중복 1건으로 기록되고, 의심 입력은 별도 격리된다. 세 결과가 서로 덮어쓰이지 않는다.
